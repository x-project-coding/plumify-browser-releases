# Plumify Browser

The desktop browser for the Plumify workspace.

[Download for Mac](https://app.plumifyai.com/desktop/download/mac)

The Mac installer supports Apple silicon and Intel Macs. The application and installer are signed and notarized for macOS. Windows is not available yet.

1. Open the downloaded disk image and drag **Plumify Browser** to **Applications**.
2. Open Plumify Browser. The Plumify workspace is already selected.
3. Choose **Sign in with your browser**, sign in at **app.plumifyai.com**, and approve the request.
4. Return to Plumify Browser to open your connected creator accounts.

Updates come from this repository. The updater ZIP is for automatic updates; use the DMG for a new installation. Checksums are included in every release.

For access or sign-in help, contact your Plumify workspace administrator.
