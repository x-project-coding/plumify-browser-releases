# Plumify Browser

The desktop browser for the Plumify workspace.

[Download for Mac](https://app.plumifyai.com/desktop/download/mac)

[Download for Windows](https://app.plumifyai.com/desktop/download/windows)

The Mac installer supports Apple silicon and Intel Macs. The application and installer are signed and notarized for macOS. The Windows installer supports Windows 64-bit (x64) and is currently unsigned; Windows may display an unknown-publisher or SmartScreen warning.

1. On Mac, open the downloaded disk image and drag **Plumify Browser** to **Applications**. On Windows, run the downloaded EXE to install **Plumify Browser**.
2. Open Plumify Browser. The Plumify workspace is already selected.
3. Choose **Sign in with your browser**, sign in at **app.plumifyai.com**, and approve the request.
4. Return to Plumify Browser to open your connected creator accounts.

Updates come from this repository. The Mac updater ZIP is for automatic updates; use the DMG or Windows EXE for a new installation. Checksums are included in every release.

For access or sign-in help, contact your Plumify workspace administrator.
